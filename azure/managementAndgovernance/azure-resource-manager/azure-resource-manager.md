# ⏺️ Azure Resource Manager (ARM)

- ARM is the management layer of Azure. It is responsible for:
  - Creating resources
  - Updating resources
  - Deleting resources
  - Organizing resources
  - Deploying resources using ARM templates or Bicep
  - Applying RBAC, Policies, and Locks

```text
Azure Resource Manager (ARM)
      ├── Management Groups
      ├── Subscriptions
      ├── Resource Groups
      └── Resources
```

- Flow

```text
Tenant (Microsoft Entra ID)
       │
       ▼
Azure Resource Manager (ARM)
       │
Management Groups
       │
Subscriptions
       │
Resource Groups
       │
Resources
```
